# 去除XML标签但保留内容的正则表达式

## 基本用法（删除标签，保留内容）

```javascript
{{内容}}.replace(/<[^>]*>|<\/[^>]*>/g, '')
```

**特点：只删除XML标签（<>和</>），保留标签内的文本内容**

## 备选版本

**版本1（更简洁）：**
```javascript
{{内容}}.replace(/<\/?[^>]+>/g, '')
```

**版本2（处理属性标签）：**
```javascript
{{内容}}.replace(/<\/?[^>]*>/g, '')
```

## 详细说明

### 正则表达式解析
- `<[^>]*>` - 匹配开始标签（如 `<提示>`、`<任意标签>`）
- `[\s\S]*?` - 非贪婪匹配任意字符，包括换行符
- `<\/[^>]*>` - 匹配结束标签（如 `</提示>`、`</任意标签>`）
- `g` - 全局匹配，处理所有符合条件的标签

### 使用示例

**输入：**
```
文字内容<提示>派对的举办状态可能与预期不同</提示>更多文字
```

**输出：**
```
文字内容派对的举办状态可能与预期不同更多文字
```

### 多标签处理

**输入：**
```
开始<tag1>内容1</tag1>中间<tag2>内容2</tag2>结束
```

**输出：**
```
开始内容1中间内容2结束
```

### 多行内容处理

**输入：**
```
文字<提示>
多行内容
换行内容
</提示>后续文字
```

**输出：**
```
文字
多行内容
换行内容
后续文字
```

## 注意事项

1. 该正则表达式只删除XML标签本身（<>和</>），保留标签内的文本内容
2. 支持多行内容和任意标签名称
3. 全局匹配处理文本中的所有标签
4. 推荐使用版本1：`{{内容}}.replace(/<\/?[^>]+>/g, '')`
