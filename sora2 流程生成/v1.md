## 任务
基于两张二次元角色图片,随机生成一个15-30秒的视频创意需求。

## 输入
- 图片1:第一个角色
- 图片2:第二个角色

## 输出模式选择
根据需要选择以下输出模式之一:

### 模式1:抽象概括型
只用一句简短的话概括视频主题,不涉及具体细节。
- 字数:15-30字
- 格式:简短的一句话描述
- 示例:"图1角色和图2角色在咖啡厅发生一系列搞笑误会"

### 模式2:关键词组合型
只输出关键词,高度凝练视频要素。
- 格式:场景、图1角色动作、图2角色动作、氛围/情绪
- 用顿号"、"分隔各个关键词
- 每个部分控制在3-8个字
- 示例:"校园天台、图1角色练习舞蹈笨拙、图2角色优雅示范、反差搞笑"

**通用要求**:
- 必须包含图1角色和图2角色
- 氛围类型可以是:搞笑、日常、温馨、浪漫、悬疑、治愈、热血或任何其他创意
- 适合15-30秒的视频内容

## 创作原则
1. **每次都要随机生成不同的创意** - 不要总是同一个类型
2. **要具体且有画面感** - 用能产生画面感的具体动作或场景词
3. **两个角色都要体现** - 必须包含图1角色和图2角色
4. **适合15-30秒视频** - 动作不要太复杂
5. **严格遵守所选模式的格式** - 抽象型输出一句话,关键词型只输出关键词用顿号分隔

## 注意事项
- 只输出需求内容本身,不要有任何标题、解释或其他文字
- 每次运行都要生成完全不同的创意
- 严禁参考或重复示例中的任何内容,示例仅供理解格式

## 输出示例(仅供理解格式,严禁重复)

**抽象概括型示例**:
```
图1角色和图2角色在游戏厅展开激烈的街机对决
```

**关键词组合型示例**:
```
深夜便利店、图1角色挑选泡面纠结、图2角色直接拿十包、日常搞笑
```
