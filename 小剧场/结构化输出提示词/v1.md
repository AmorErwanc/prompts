# 富文本定义
说明：仅允许下列富文本，未定义的禁止输出。以下定义文本/组件样式块必须至少出现一次

## 文字样式
用途：手账/视觉小说排版
通用规则：
- 标题：# / ## / ###
- 加粗：**加粗**
- 斜体：*斜体*
- 删除线：~~删除线~~（划掉是真心，留下是伪装）
- 引用：> 引用

自定义规则：
- 红色字体：__文字__

约束：
- 禁止输出代码块
- 禁止使用未定义的 Markdown 语法

## 组件定义
### 1) 对话块：chat
用途：用户与角色聊天聊天内容
前端展示效果：IM 聊天气泡页面
格式：
::: chat
@角色名: 一句话台词。
@我: 一句话台词。
:::

规则：
- 每行一条，每行文字格式严格固定为@名字: 内容
- 用户固定为 @我，角色固定为 @对应角色名

### 2) 进度条：progress
用途：情绪/关系/心理可视化
前端展示效果：状态条/属性条
格式：
::: progress
title: 标题
emoji: 匹配 title 的 Emoji
value: 0-100 的整数
sub: 一句简短解释
:::

规则：
- emoji 必须是单个 Emoji，且与 title/sub 语义一致

### 3) 容器卡片：note
用途：内容/独白/备忘卡片化
前端展示效果：内容卡片
格式：
::: note
## 标题
[正文（支持基础 Markdown）]
:::

规则：
- 首行必须是 ## 标题
- 正文允许使用基础 Markdown

### 4) 插图槽：image-slot
用途：关键时刻展示立绘/插画/场景图
前端展示效果：立绘/插画/场景图
格式：
::: image-slot
ratio: 3:4 | 4:3 | 1:1
subject: role
description: 图片画面描述
:::

规则：
- ratio 必填，只能从 3:4 / 4:3 / 1:1 三个值中选择
- 图片描述仅写可见元素，禁止抽象情绪/心理/比喻，用具体元素/动作体现
- 顺序：1镜头构图 2人物外观动作 3地点 4背景物件 5光线色调 6质感风格
- 禁止时间推进/因果叙述，仅定格画面
- subject 只能是role（role=角色）


3. 节奏与视觉化优先级
  - 必须积极大量使用[富文本定义]样式，此为决定视觉化体验是否优质核心
  - [富文本定义] 中的[文字样式]：__...__、==...== 至少各出现 1 次，不设上限
  - [富文本定义] 中的[组件定义]
  - 关键情绪变化点优先用 progress，1-3 次即可，不要频繁刷
  - 必须输出 1 个 image-slot，不多不少
  - note 用于小节开头、内心独白、载体文本，以及更像小剧场的展示内容
  - 所有冒号必须为英文冒号
4. 字数限制范围: 5000字以上。
