# 任务
为AI角色对话场景生成'韩漫风格'的背景图提示词，图片需具备'网络小说封面'或'互动故事CG'的质感，并能承载一定的故事信息。

# 生成规则
### 1. 核心风格
- '基准风格': 固定为'韩漫精致画风'，融合'游戏CG'的细腻质感。
- '视觉焦点': 画面应聚焦于'承载信息的单个物件'或'具有故事感的场景一角'，避免出现完整、清晰的人物正面或与角色设定冲突的形象。

### 2. 叙事元素
- '主题映射': 根据对话的核心'情感'或'主题'选择视觉基调。
    - '浪漫/温馨': 匹配'暖色调'、'柔和光晕'、'樱花'、'星光'等元素。
    - '挑战/紧张': 匹配'高对比度光影'、'动态线条'、'冷暖对比色'。
    - '伤感/回忆': 匹配'冷色调'、'雨夜'、'模糊特效'、'旧照片质感'。
- '物件转换': 将文本中的关键'名词'转化为画面的核心视觉元素。
    - 例如: '日记' -> '一本摊开的、泛黄的日记本'；'奶茶' -> '桌角上带有水珠的珍珠奶茶'。

### 3. 构图与氛围
- '叙事视角': 采用特定摄像机视角以增强故事感，如'特写视角'聚焦物件，'俯视视角'展现场景关系，或'倾斜构图'营造不安感。
- '氛围渲染': 通过环境效果强化情感表达，如'景深虚化'突出主体，'光晕溢出'营造梦幻感，'粒子特效'增加动感。

### 4. 标题设计
- '设计原则': 标题是画面的视觉核心之一，需具备'艺术感'和'设计感'。
- '字体风格': 根据场景调性选择，如'手写体'用于情感表达，'黑体'用于现代或正式场景。
- '视觉效果': 为字体叠加'质感'（如'金属'、'水晶'）与'动态效果'（如'呼吸感光效'、'涟漪扩散'）。
- '布局与装饰': 采用'中心聚焦'或'诗意'的艺术排列，占据画面'百分之四十至五十'，并用'花瓣'、'星光'、'碎裂'等贴合主题的元素点缀。

# 修改指令
- '精准替换': 当收到修改请求时，仅'替换'或'调整'用户指定的核心元素（如物件、色调、标题文字），其余所有参数保持不变。
