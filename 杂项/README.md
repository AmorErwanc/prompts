# 对话数据批量转换工具

本项目用于批量处理对话数据CSV文件，将其按session（会话）整理，并导出为两种JSON格式的Markdown文档。

## 功能说明

支持两种数据源的处理：
1. **非脱敏版**：包含完整的会话ID和用户ID信息
2. **脱敏版**：不显示任何敏感ID信息，仅显示会话编号

### 数据源对比

| 数据源 | 目录 | CSV字段 | CSV文件名 | 输出目录 |
|--------|------|---------|-----------|----------|
| 非脱敏版 | `对话数据导出/` | 创建时间, 会话ID, 用户ID, 用户输入, AI回复, 完整消息 | `{pipeid}_低质量用户输入.csv`<br>`{pipeid}_高质量用户输入.csv` | `markdown_outputs_非脱敏/` |
| 脱敏版 | `对话数据导出_脱敏版/` | 会话编号, 对话序号, 用户输入, AI输出, messages | `低质量输入测试集.csv`<br>`高质量输入测试集.csv` | `markdown_outputs_脱敏/` |

### 输出格式

两种数据源都会生成相同的两种JSON格式：

#### 版本A：原messages格式
按会话分组，每个消息包含role和content字段：
```json
[
  {
    "role": "user",
    "content": "用户输入内容"
  },
  {
    "role": "assistant",
    "content": "AI输出内容"
  }
]
```

#### 版本B：优化后messages格式
按会话分组，每对消息包含user和assistant字段：
```json
[
  {
    "user": "用户输入内容",
    "assistant": "AI输出内容"
  }
]
```

### 输出示例对比

#### 非脱敏版输出

```markdown
\`\`\`json

  {
    "role": "user",
```


## 使用方法

### 1. 处理非脱敏版数据

```bash
python3 batch_convert_non_desensitized.py
```

**处理说明**：
- 读取 `对话数据导出/` 目录
- 按创建时间排序对话记录
- 输出包含完整的 session_id 和 user_id 信息
- 输出到 `markdown_outputs_非脱敏/` 目录

### 2. 处理脱敏版数据

```bash
python3 batch_convert_desensitized.py
```

**处理说明**：
- 读取 `对话数据导出_脱敏版/` 目录
- 按对话序号排序对话记录（保证聊天顺序正确）
- **不显示任何ID信息**，仅显示"会话1"、"会话2"等编号
- 输出到 `markdown_outputs_脱敏/` 目录

## 关键实现细节

### 非脱敏版
- **分组**：按 `会话ID` 分组；若缺失则用占位 `"<EMPTY_SESSION_ID>"`
- **排序**：同一会话内按 `创建时间` 升序，兼容常见日期格式
- **ID显示**：在markdown标题中显示 `session_id` 和 `user_id`
- **编码**：读取时使用 `utf-8-sig` 以兼容带BOM的CSV；写出为 `utf-8`

### 脱敏版
- **分组**：按 `会话编号` 分组（会话1、会话2等）
- **排序**：同一会话内按 `对话序号` 升序，确保聊天顺序正确
- **ID显示**：**完全不显示**任何ID信息，仅显示会话编号
- **编码**：读取时使用 `utf-8-sig` 以兼容带BOM的CSV；写出为 `utf-8`

## 使用场景

### 非脱敏版

- 需要追溯具体会话和用户的场景

### 脱敏版
- 对外分享和演示

- 需要保护用户隐私的场景
- 公开发布的数据集

## 常见问题

### 时间格式不统一（非脱敏版）
脚本已尝试多种常见格式解析；若仍无法解析，请规范化 `创建时间` 字段。

### 对话顺序混乱（脱敏版）
脚本已按 `对话序号` 字段排序，确保同一会话内的对话按1, 2, 3...顺序排列。

### 大文件处理
Markdown汇总较长，建议使用编辑器的折叠或搜索功能快速定位会话。

### 安全与隐私
- **非脱敏版**：包含真实ID信息，请妥善保管，不要对外分享
- **脱敏版**：不包含任何ID信息，适合对外分享和发布

## 维护建议

- 新增CSV后重复执行对应脚本即可生成最新输出
- 非脱敏版和脱敏版可以独立运行，互不影响
- 若调整字段名或新增列，请同步更新对应脚本中的取值逻辑
- 输出文件较大，已在 `.gitignore` 中排除，避免提交到版本库
