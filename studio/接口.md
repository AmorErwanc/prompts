## 请求 studio 接口
接口 post 请求：
curl -X POST "https://cyapi-t.ideaflow.pro/uat/pipe/chat" \
-H "Authorization: 你的Authorization值" \
-H "Draft: 1" \
-H "Content-Type: application/json" \
-d '{
  "event": "input",
  "pipeId": "000004712327027238682646",
  "in": [
    {
      "type": "img",
      "name": "k_5",
      "val": "https://img.ideaflow.pro/image/1ba15eb24243ca2ddef07cf728b808f1.jpg"
    },
    {
      "type": "img",
      "name": "k_2",
      "val": "https://img.ideaflow.pro/image/9b9ab3488ad9d3afc219f7d7191c415e.jpg"
    },
    {
      "type": "str",
      "name": "k_3",
      "val": "2"
    },
    {
      "type": "str",
      "name": "k_4",
      "val": "女"
    }
  ]
}'

{
  "code": 0,
  "msg": "success",
  "errStyle": "toast",
  "errTitle": null,
  "data": "900004722492942567620608"
}

-H "Authorization: 你的Authorization值" \
-H "Draft: 1"
