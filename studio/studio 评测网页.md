# studio 评测网页

## 网页功能

### 多次批量请求接口

### 支持动态添加多种接口

## 接口

### 请求接口

- 可变动
  
    - 请求头
      
        - Authorization
          
            - 必写
              
        - draft
          
            - 可选
              
    - 请求体
      
        - pipeid
          
            - 调用不同 workflow 的参数
              
        - In
          
            - 输入类型
              
                - 图片输入
                  
                    - img
                      
                - 文本输入
                  
                    - str
                      
                - 数字输入
                  
                    - num
                      
            - 输入名称
              
                - 支持自定义 in 的 name 值
                  
            - 输入内容
              
                - 支持定义输入值（且输入值保留缓存）
                  
        - 支持In 请求参数的增删
          
### 查询接口

- 支持显示内容
  
    - 图片
      
    - 文本
      
    - 视频
